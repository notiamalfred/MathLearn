Binomial Theorem — Solution

2026–2027 S.4 Mathematics (Extended Part Module 2) Chapter 2 — Common technique, expansions and DSE examples.

Summary Examples

A) Common Technique in Binomial Theorem

Summary \(C_r^n\)

Let \(n\) and \(r\) be non-negative integers, where \(n \ge r\). \(C_n^n = C_0^n = 1\).

Factorial Notation: \(n! = n(n-1)(n-2)\dots(2)(1)\)

Combination Symbol: \(C_r^n = \dfrac{n!}{r!(n-r)!}\)

Note:

\(C_r^n = C_{n-r}^n\) \(C_1^n = n\) \(C_2^n = \dfrac{n(n-1)}{2}\) \(C_3^n = \dfrac{n(n-1)(n-2)}{6}\)

Binomial Theorem

\((a+b)^n = C_0^n a^n + C_1^n a^{n-1} b + C_2^n a^{n-2} b^2 + \dots + C_r^n a^{n-r} b^r + \dots + C_n^n b^n\) \(= \displaystyle\sum_{r=0}^{n} C_r^n a^{n-r} b^r\)

The general term / \((r+1)^{\text{th}}\) term of the expansion \(= C_r^n a^{n-r} b^r\).

Examples

Example 1 — Type 1: The \(C_r^n\) notation

Simplify \(C_r^n \div C_{r-1}^{n-1}\).

Example 2 — Expand in ascending powers of \(x\)

Expand the following expressions in ascending powers of \(x\).

(a) \((3x - 1)^3\)
(b) \((x + 1)^4 (x - 1)^4\)
(c) \((1 - x + 2x^2)^3\)

(a)

\((3x-1)^3 = (-1+3x)^3\) \(= (-1)^3 + 3(-1)^2(3x) + 3(-1)(3x)^2 + (3x)^3\) \(= -1 + 9x - 27x^2 + 27x^3\)

(b)

\((x+1)^4 (x-1)^4 = (x^2-1)^4\) \(= (1-x^2)^4\) \(= (-1)^4 + 4(-1)^3(x^2) + 6(-1)^2(x^2)^2 + 4(-1)(x^2)^3 + (x^2)^4\) \(= 1 - 4x^2 + 6x^4 - 4x^6 + x^8\)

(c)

\((1-x+2x^2)^3 = \left[1 + (-x + 2x^2)\right]^3\) \(= 1 + 3(-x + 2x^2) + 3(-x + 2x^2)^2 + (-x + 2x^2)^3\) \(= 1 - 3x + 6x^2 + 3(x^2 - 4x^3 + 4x^4)\) \(\quad + \left[-x^3 + 3(-x)^2(2x^2) + 3(-x)(2x^2)^2 + (2x^2)^3\right]\) \(= 1 - 3x + 9x^2 - 13x^3 + 18x^4 - 12x^5 + 8x^6\)

★ Always distinct the constant term in trinomial expansion.

Example 3 — [2024-DSE-M2-Q3]

Let \(m\) be a positive integer. Consider the expansion of \(\left(x^m - \dfrac{2}{x}\right)^{24}\) in descending powers of \(x\).

(a) Find the first 3 terms of the expansion.
(b) If the \(19^{\text{th}}\) term of the expansion is a constant, find \(m\) and the coefficient of \(x^{60}\) in the expansion.

\(\left(x^m - \dfrac{2}{x}\right)^{24} = (x^m)^{24} + C_1^{24}(x^m)^{23}\left(-\dfrac{2}{x}\right) + C_2^{24}(x^m)^{22}\left(-\dfrac{2}{x}\right)^2 + \dots\) \(= x^{24m} - 48x^{23m-1} + 1104x^{22m-2} + \dots\)

First 3 terms: \(x^{24m}\), \(-48x^{23m-1}\) and \(1104x^{22m-2}\).

(b)

General term: \(C_r^{24}(x^m)^{24-r}\left(-\dfrac{2}{x}\right)^r = C_r^{24}(-2)^r x^{24m-mr-r}\)

The \(19^{\text{th}}\) term: \(C_{18}^{24}(-2)^{18} x^{6m-18}\). For constant term, \(6m - 18 = 0 \Rightarrow m = 3\).

For coefficient of \(x^{60}\):

\(24 \times 3 - 3r - r = 60\) \(72 - 4r = 60\) \(r = 3\)
Coefficient \(= C_3^{24}(-2)^3 = -16192\)

Example 4 — [2017-DSE-M2-Q2]

Let \((1+ax)^8 = \displaystyle\sum_{k=0}^{8} \lambda_k x^k\) and \((b+x)^9 = \displaystyle\sum_{k=0}^{9} \mu_k x^k\), where \(a\) and \(b\) are constants. It is given that \(\lambda_2 : \mu_7 = 7 : 4\) and \(\lambda_1 + \mu_8 + 6 = 0\). Find \(a\).

\((1+ax)^8 = \displaystyle\sum_{k=0}^{8} C_k^8 a^k x^k\) and \((b+x)^9 = \displaystyle\sum_{k=0}^{9} C_k^9 b^{9-k} x^k\) \(\lambda_k = C_k^8 a^k\) and \(\mu_k = C_k^9 b^{9-k}\)
\(\dfrac{C_2^8 a^2}{C_7^9 b^{9-7}} = \dfrac{7}{4}\) and \(C_1^8 a + C_8^9 b^{9-8} + 6 = 0\) \(\dfrac{a^2}{b^2} = \dfrac{9}{4}\) and \(8a + 9b + 6 = 0\)
\(b = \dfrac{2}{3}a\) or \(b = -\dfrac{2}{3}a\)

When \(b = \dfrac{2}{3}a\):

\(8a + 9\left(\dfrac{2}{3}a\right) + 6 = 0\) \(a = -\dfrac{3}{7}\)

When \(b = -\dfrac{2}{3}a\):

\(8a + 9\left(-\dfrac{2}{3}a\right) + 6 = 0\) \(a = -3\)

Example 5 — [2022-DSE-M2-Q5]

Let \(n\) be an integer greater than 1. Define \((a+x)^n = \displaystyle\sum_{k=0}^{n} \mu_k x^k\) where \(a\) is a constant. It is given that \(\mu_2 = -10\).

(a) Explain why \(a\) is a negative number and \(n\) is an odd number.
(b) Let \((bx-1)^n = \displaystyle\sum_{k=0}^{n} \lambda_k x^k\), where \(b\) is a constant. If \(\lambda_0 = \mu_0\) and \(\lambda_1 = 2\mu_1\), find \(a\), \(b\) and \(n\).

(a)

\((a+x)^n = a^n + na^{n-1}x + \dfrac{n(n-1)}{2} a^{n-2} x^2 + \dots\) \(\mu_2 = -10\) \(\dfrac{n(n-1)}{2} a^{n-2} = -10\) \(n(n-1) a^{n-2} = -20\)

Since \(n\) is an integer greater than 1, \(n(n-1)\) must a positive integer, which means \(a^{n-2}\) is a negative number, which means \(a\) is negative number and \(n\) is an odd number.

(b)

Note that \(\mu_0 = a^n\), \(\mu_1 = n a^{n-1}\).

\((bx-1)^n = (-1+bx)^n = (-1)^n + n(-1)^{n-1}(bx) + \dfrac{n(n-1)}{2}(-1)^{n-2}(bx)^2 + \dots\) \(\lambda_0 = (-1)^n\), \(\lambda_1 = bn(-1)^{n-1}\)
\(a^n = (-1)^n\) and \(2na^{n-1} = bn(-1)^{n-1}\) \(a = -1\) and \(2n(-1)^{n-1} = bn(-1)^{n-1}\) \(\therefore b = 2\)
\(\mu_2 = -10\) \(\dfrac{n(n-1)}{2}(-1)^{n-2} = -10\) \(n(n-1) = 20\) \(n = 5\) or \(n = -4\) (rej.)

★ Note that you need 3 equations to solve 3 unknowns.
