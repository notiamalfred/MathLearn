[2022- DSE- M2- Q5] Let \(n\) be an integer greater than 1. Define \((a + x)^n = \sum_{k = 0}^{n}\mu_k x^k\) where \(a\) is a constant. It is given that \(\mu_2 = - 10\) . (a) Explain why \(a\) is a negative number and \(n\) is an odd number. (b) Let \((bx - 1)^n = \sum_{k = 0}^{n}\lambda_k x^k\) , where \(b\) is a constant. If \(\lambda_0 = \mu_0\) and \(\lambda_1 = 2\mu_1\) , find \(a\) , \(b\) and \(n\) . (a) \[(a + x)^n = a^n +na^{n - 1}x + \frac{n(n - 1)}{2} a^{n - 2}x^2 +\dots\] \[\mu_2 = -10\] \[\frac{n(n - 1)}{2} a^{n - 2} = -10\] \[n(n - 1)a^{n - 2} = -20\] Since \(n\) is an integer greater than 1, \(n(n - 1)\) must a positive integer, which means \(a^{n - 2}\) is a negative number, which means \(a\) is negative number and \(n\) is an odd number. (b) Note that \(\mu_0 = a^n\) , \(\mu_1 = na^{n - 1}\) \[(bx - 1)^n = (-1 + bx)^n = (-1)^n +n(-1)^{n - 1}(bx) + \frac{n(n - 1)}{2} (-1)^{n - 2}(bx)^2 +\dots\] \[\lambda_0 = (-1)^n, \lambda_1 = bn(-1)^{n - 1}\] \[a^n = (-1)^n \text{and} 2na^{n - 1} = bn(-1)^{n - 1}\] \[a = -1 \text{and} 2n(-1)^{n - 1} = bn(-1)^{n - 1}\] \[\therefore b = 2\] \[\mu_2 = -10\] \[\frac{n(n - 1)}{2} (-1)^{n - 2} = -10\] \[n(n - 1) = 20\] \[n = 5 \text{or} n = -4 \text{(rej.)\] Note that you need 3 equations to solve 3 unknowns.
