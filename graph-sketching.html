Sketching the Graph

Order of features

You may follow the following order of features to sketch the graph of a quadratic function:

  1. y-intercept
  2. Direction of opening
  3. x-intercepts (if any)
  4. Vertex (if needed)

Example 1

Sketch the quadratic function y = x² − 3x + 2.

Locating the x-intercepts: 1 and 2; y-intercept: 2. Direction: open upwards.

Example 2

Sketch the quadratic function y = x² + 4x + 10.

y-intercept: 10; direction: open upwards; AOS: x = −2. Since there is no x-intercepts, sub x = −2 to find the vertex: (−2, 6).

Multiple Choice Questions

Example 1

The figure shows the graph of y = ax² + bx + c. Which of the following is true?

A. a > 0, c > 0 and b² > 4ac
B. a > 0, c < 0 and b² < 4ac
C. a < 0, c < 0 and b² > 4ac
D. a < 0, c < 0 and b² < 4ac

  1. Open downwards → a < 0
  2. y-intercept → c < 0
  3. Two x-intercepts → b² − 4ac > 0

P.S. Sign of b can be evaluated in two ways:

  1. −b/(2a) > 0 → b > 0
  2. f(x) < 0, b < 0; f(x) > 0, b > 0

Example 2

The figure shows the graph of y = a(x − b)². Which of the following is true?

A. a > 0 and b > 0
B. a > 0 and b < 0
C. a < 0 and b > 0
D. a < 0 and b < 0

  1. Open upwards → a > 0
  2. Axis of symmetry: x = b > 0

Example 3

Refer to the graph y = ax² − 2bx + c. Which of the following is true?

I. a < 0
II. c < 0
III. b < 0
IV. ac < b²

A. I and III only

2. y-intercept → c > 0 3. Axis of symmetry: x = −(−2b)/(2a) = b/a > 0 Given that a < 0, which means b < 0 4. Two x-intercepts: (−2b)² − 4ac > 0 4b² > 4ac b² > ac

Example 4

Refer to the graph of y = a(x − h)² + k. Which of the following is true?

I. a > 0
II. h > 0
III. k < 0

A. I and II only
B. I and III only
C. II and III only
D. I, II and III

  1. Open upwards → a > 0
  2. Vertex (h, k), where h is positive and k is negative
