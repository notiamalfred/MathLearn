Type 1 — General Form y = ax² + bx + c

Coefficients and their roles

Coefficient a determines 1) Direction of opening and 2) Wideness of the parabola.

  • If a < 0, the parabola will open downward.
  • If a > 0, the parabola will open upward.
  • The larger |a| is, the narrower the opening gets.

Coefficient c determines the y-intercept of the parabola.

By substituting x = 0 to the quadratic equation, the value of y is always equal to the constant c.

Coefficient b determines the axis of symmetry of the parabola.

The axis of symmetry is a vertical line that passes through the vertex of the parabola and lies exactly midway between the two x-intercepts (if they exist).

Equation of the axis of symmetry is x = −b/(2a) (x-coordinate of the vertex).

Type 2 — Vertex Form y = a(x − h)² + k

Geometric features from vertex form

By converting the General Form y = ax² + bx + c into the Vertex Form y = a(x − h)² + k, we can directly identify the critical geometric features of the parabola:

  • Coordinates of the vertex: (h, k), which is the lowest point (for a > 0) or the highest point (for a < 0).
  • Equation of the axis of symmetry: the vertical line x = h.
  • Minimum value k (for a > 0) or maximum value k (for a < 0) of y.

Two methods to find the vertex

1. Method of completing square

ax² + bx + c = a(x² + (b/a)x) + c = a(x² + (b/a)x + (b/(2a))²) − a(b/(2a))² + c = a(x + b/(2a))² − a(b/(2a))² + c

2. By substitution

By comparing the two forms, h = −b/(2a). Since we know that the axis of symmetry passes through the vertex as well, we can find the value of k by substituting the value of h into x after computation.

Type 3 — Intercept Form y = a(x − α)(x − β)

From roots to function

By solving quadratic equation y = 0, we can rewrite a quadratic function in forms of α and β. However, in a function sense, the graph can be enlarged or reflected in different scales, such that adding a leading coefficient a is necessary.

Example 1 — Given 3 Random Points

Find the quadratic function passing through points (0, 10), (1, 20) and (5, 0).

Let the function be y = ax² + bx + 10 By putting (1, 20) and (5, 0), (20) = a(1)² + b(1) + 10 … (1) (0) = a(5)² + b(5) + 10 … (2) Solving, a = −3, b = 13 y = −3x² + 13x + 10

Example 2 — Given Vertex

Find the quadratic function with vertex (1, 2), and passes through the point (2, −1).

Let the function be y = a(x − 1)² + 2 Sub (2, −1), −1 = a(2 − 1)² + 2 a = −3

The quadratic function: y = −3(x − 1)² + 2.

Example 3 — Given x-intercepts

Find the quadratic function with x-intercepts 4 and 5, and y-intercept 10.

Let the function be y = a(x − 4)(x − 5) By putting y-intercept, 10 = a(0 − 4)(0 − 5) a = 1/2 y = (1/2)(x − 4)(x − 5)
