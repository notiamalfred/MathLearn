Worked Examples

Example 1

If β is a root of the equation 3x² + 2x − 3 = 0, then 6β² + 4β − 7 =

A. 0   B. −1   C. 4   D. −4

When seeing "… is a root", immediately substitute into the equation. Rewrite the expressions into multiples of the unknowns in the equation.

Method 1 (LQ)

3β² + 2β − 3 = 0 3β² + 2β = 3 6β² + 4β = 6 ∴ 6β² + 4β − 7 = 6 − 7 = −1

Method 2 (MC)

Press FMLA 01 to get the value of β. Substitute either value into 6β² + 4β − 7 would get −1.

Example 2

If (a − 1)² − 3(a − 1) + 2 = 0 and (b − 1)² − 3(b − 1) + 2 = 0, where a < b, find the value of b − a.

A. −1   B. 0   C. 1   D. 2

Consider the expression as a quadratic equation: x² − 3x + 2 = 0, where a − 1 and b − 1 are roots of the equation.

★ Observe that the two equations given has exactly the same format of positioning of unknown.

Example 3

Solve the equation 2ax(2 − ax) + ax = 2, where a ≠ 0.

A. x = 0
B. x = 1 / (2a)
C. x = 1 / (2a) or 2 / a
D. x = 2a or a

Method 1 (LQ)

2ax(2 − ax) + ax = 2 2ax(2 − ax) − (2 − ax) = 0 (2 − ax)(2ax − 1) = 0 x = 2/a or x = 1/(2a)

Method 2 (MC)

Substitute a random number into the extra variable a, note that the number you choose needs to be unique for each of the options.

For example, when a = 2, the equation becomes 8x² − 10x + 2 = 0, solution becomes x = 1/4 or x = 1. By checking the options, option C matches the substitution.

Completing Square

Rewrite ax² + bx + c as a(x − h)² + k.

Introduction Type 1 Type 2 Examples

Introduction

What is Completing Square?

A quadratic expression with form ax² + bx + c can be rewritten in the form of a(x − h)² + k, which we name this process as "Completing Square".

For example, x² + 4x + 5 = (x + 2)² + 1.

Type 1 — Leading Coefficient as 1

Quadratic expressions in the form x² + bx + c

  1. Divide the coefficient of x (i.e. b) by 2 to obtain the value of h in the form of (x + h)² + k.

    e.g. For x² + 4x + 5, h = 4/2 = 2, i.e. (x + 2)² + k e.g. For x² − 6x − 3, h = −6/2 = −3, i.e. (x + (−3))² + k

  2. Add the term (b/2)² (you may neglect the negative sign), and subtract back (b/2)² such that x² + bx + (b/2)² form a perfect square.

    e.g. x² + 4x + 5 = x² + 4x + (2)² − (2)² + 5 e.g. x² − 6x − 3 = x² − 6x + (3)² − (3)² − 3

  3. Simplify the residue expression (−(b/2)² + c).

    e.g. x² + 4x + 5 = (x + 2)² − 4 + 5 = (x + 2)² + 1 e.g. x² − 6x − 3 = (x − 3)² − 9 − 3 = (x − 3)² − 12

Type 2 — Leading Coefficient in Forms of Non-1

Quadratic expressions in the form ax² + bx + c

  1. Take out the factor a for the terms ax² and bx; ignore the constant term c.

    e.g. −x² + 4x + 8 = −(x² − 4x) + 8 e.g. 3x² + 6x − 1 = 3(x² + 2x) − 1

  2. Add and subtract the term (b/2)² such that x² + bx + (b/2)² inside the bracket form a perfect square.

    e.g. −x² + 4x + 8 = −(x² − 4x + (2)² − (2)²) + 8 e.g. 3x² + 6x − 1 = 3(x² + 2x + (1)² − (1)²) − 1

  3. Simplify the residue expression by −a(b/2)² + c; be careful on dealing with brackets.

    e.g. −x² + 4x + 8 = −(x² − 4x + 4) + 4 + 8 = −(x − 2)² + 12 e.g. 3x² + 6x − 1 = 3(x² + 2x + 1) − 3 − 1 = 3(x + 1)² − 4

Examples

Type 1 — Example 1

y = x² − 3x + 2 y = x² − 3x + 1.5² − 1.5² + 2 y = (x − 1.5)² − 0.25

Type 1 — Example 2

y = x² + (1/3)x + 1 y = x² + (1/3)x + (1/6)² − (1/6)² + 1 y = (x + 1/6)² + 35/36

Type 2 — Example 1

y = −2x² + 2x − 1 y = −2(x² − x) − 1 y = −2[x² − x + (1/2)² − (1/2)²] − 1 y = −2(x − 1/2)² + 1/2 − 1 y = −2(x − 1/2)² − 1/2

Type 2 — Example 2

y = (1/3)x² − x + 2 y = (1/3)(x² − 3x) + 2 y = (1/3)[x² − 3x + (3/2)² − (3/2)²] + 2 y = (1/3)(x − 3/2)² − 3/4 + 2 y = (1/3)(x − 3/2)² + 5/4

Discriminant — Proof of Statements

Using Δ = b² − 4ac with completing square.

Introduction Proof Type 1 Graph Example

Introduction

What the discriminant can do

The discriminant of a quadratic equation Δ = b² − 4ac is not only useful for finding unknown values; with the aid of completing the square, it can also prove that a statement or equation always holds true for all real values.

  1. Express and simplify the discriminant.
  2. Completing the square for the discriminant to find max/min values.
  3. Comparing values to complete the proof.

Type 1 — Proof of Statements Always Hold True

Example 1

For the equation x² + ax + (a − 2) = 0, prove that it has 2 distinct real roots for any real values of a.

Δ = a² − 4(1)(a − 2) = a² − 4a + 8 = a² − 4a + 2² − 2² + 8 = (a − 2)² + 4 ≥ 4 > 0

∴ For any real number a, the equation has 2 distinct real roots.

★ Complete the square if the expression of Δ is not a perfect square. Then, you will notice that the minimum value of the expression is 4.

Graph Example

Example 2

The figure shows the graph of y = x² + mx + n, where m < 0. The graph touches the x-axis at the point P, and it cuts the y-axis at the point Q. QR is a horizontal line.

Make use of the information given: "touch the x-axis" to deduce the relationship between unknowns.

(a) Express n in terms of m.

Δ = 0 m² − 4(1)(n) = 0 n = m²/4

(b) Find, in terms of m, the coordinates of P, Q and R.

By substituting n = m²/4 into y = x² + mx + n, we have y = x² + mx + m²/4.

When y = 0, x² + mx + m²/4 = 0 (x + m/2)² = 0 x = −m/2

The coordinates of P are (−m/2, 0).

When x = 0, y = (0)² + m(0) + m²/4 = m²/4

The coordinates of Q are (0, m²/4).

When y = m²/4, m²/4 = x² + mx + m²/4 x² + mx = 0 x = −m or x = 0

The coordinates of R are (−m, m²/4).

(c) Find the values of m and n if the area of ΔPQR is 27 sq units.

Let H be a point on QR such that PH ⊥ QR.

QR = −m − 0 = −m, PH = m²/4
(1/2)(−m)(m²/4) = 27 m³ = −216 m = −6

By substituting m = −6 into n = m²/4, we have n = (−6)²/4 = 9.

Sum and Product of Roots

α + β = −b/a and αβ = c/a.

Basics Type 1 Type 2 Type 3

Basics

Formulas and identities

For a quadratic equation that is in form of ax² + bx + c = 0:

(x − α)(x − β) = 0 x² − (α + β)x + αβ = 0 … (1) ax² + bx + c = 0 x² + (b/a)x + (c/a) = 0 … (2) ∴ α + β = −b/a, αβ = c/a

Three useful identities

1. α² + β² = (α + β)² − 2αβ 2. (α − β)² = (α + β)² − 4αβ 3. α − β = √[(α + β)² − 4αβ]  (for α > β) = −√[(α + β)² − 4αβ]  (for α < β)

Type 1 — Forming Quadratic Equations with Roots

Example 1

If the roots of the equation x² + √3 x − 4 = 0 are α and β, form a quadratic equation in t whose roots are α − β and β − α.

Step 1: write down the sum and product of roots of the original equation.

α + β = −√3 / 1 = −√3 αβ = −4 / 1 = −4

Step 2: find the new sum and product of roots in terms of the original one.

New sum of roots = (α − β) + (β − α) = 0 New product of roots = (α − β)(β − α) = −(α − β)² = −[(α + β)² − 4αβ] = −[(−√3)² − 4(−4)] = −19

Step 3: express the answer in terms of the format t² − (sum of roots)t + (product of roots) = 0.

The required quadratic equation: t² − 19 = 0.

Type 2 — Making Use of the Unknown with Given Roots

Example 2

It is given that α and β are the roots of the quadratic equation x² + mx + n = 0; α + 2 and β + 2 are the roots of the equation x² + nx + m = 0. Find the values of m and n.

★ Step 1: list the original and new sum/product of roots.

α + β = −m, αβ = n ∴ (α + 2) + (β + 2) = −n α + β + 4 = −n −m + 4 = −n m − n = 4 … (1)

★ Step 2: Substitute the values from original sum/product of roots to the new one.

(α + 2)(β + 2) = m αβ + 2(α + β) + 4 = m n + 2(−m) + 4 = m 3m − n = 4 … (2) (2) − (1): 2m = 0 m = 0

By substituting m = 0 into (1), we have:

0 − n = 4 n = −4

Example 3

If α and β are the roots of the quadratic equation x² − 5x + p = 0, then α² + 5β =

A. 10 − p
B. 15 − p
C. 20 − p
D. 25 − p

★ … are the roots →

  1. Sub to the equation
  2. Apply sum/product of roots

For those with different powers, try to reduce them into same powers (1 or 2).

α² − 5α + p = 0 α² = 5α − p α² + 5β = 5α + 5β − p = 5(5) − p = 25 − p

MC: Sub a value to p and then press calculator.

e.g. When p = 4, x² − 5x + 4 = 0 ⇒ x = 1 or x = 4.

α² + 5β = 1² + 5(4) = 21 (D)

Example 4

The figure shows the graph of y = −4x² + 12x − (k + 3). It cuts the x-axis at two points A and B, and OA : OB = 1 : 5. Find the value of k.

Set up unknowns to represent the roots.

Let (α, 0) and (β, 0) be the coordinates of A and B respectively.

∵ OA : OB = 1 : 5

Note that OA and OB are distances which are equal to the roots.

∴ α and 5α are roots of −4x² + 12x − (k + 3) = 0.

Complex Numbers

i, a + bi, conjugates, powers and series.

Basics Examples

Basics

Definition of i

Definition of i: √(−1)

i4n + r = ir for non-negative integers n and r.

Example: i2026 = i4 × 506 + 2 = i² = −1

General form a + bi

For any complex number, we consider the general form of a + bi (a and b are real numbers):

Real parta
Imaginary partb
Conjugate / another roota − bi
Reciprocal1/(a + bi) = 1/(a + bi) × (a − bi)/(a − bi)

Note: classifications of rational numbers is not applicable in numbers with non-zero imaginary part.

Examples

Example 1

(a) Express 1/(1 + 2i) in the form a + bi, where a and b are real numbers. (2 marks)

1/(1 + 2i) = 1/(1 + 2i) × (1 − 2i)/(1 − 2i) = 1/5 − (2/5)i

(b) One of the roots of the quadratic equation x² + px + q = 0 is 10/(1 + 2i).

(i) Find p and q. (3 marks)

10/(1 + 2i) = 10(1/5 − (2/5)i) = 2 − 4i Another root = 2 + 4i Sum of roots = −p/1 = (2 + 4i) + (2 − 4i) p = −4 Product of roots = q = (2 + 4i)(2 − 4i) q = 20

Alternative:

Another root = 10/(1 − 2i) = 10/(1 − 2i) × (1 + 2i)/(1 + 2i) = 2 + 4i

(ii) Find the range of values of r such that the quadratic equation x² + px + q = r has real roots. (2 marks)

Has real roots include the situation of 1 and 2 roots.

x² − 4x + 20 − r = 0 Δ = (−4)² − 4(1)(20 − r) ≥ 0 4r − 64 ≥ 0 r ≥ 16

Example 2

Let u = 7/(a + i) and v = 7/(a − i), where a is a real number. Which of the following must be true?

I. uv is a rational number.
II. The real part of u is equal to the real part of v.
III. The imaginary part of 1/u is equal to the imaginary part of 1/v.

A. I only  B. II only  C. I and III only  D. II and III only

I: uv = 49/(a² + 1), however a may not be rational.

★ Use different forms of u to evaluate quicker.

1/u = a/7 + (1/7)i, 1/v = a/7 − (1/7)i

∴ Only II is true (B).

Alternative: since a is not a constant, substitute a value into a and try by calculator.

Example 3

If (a + 3i)(2 − 3i) = b, where a and b are real numbers, find the values of a and b.

(a + 3i)(2 − 3i) = 2a + 6i − 3ai − 9i² = (2a + 9) + (6 − 3a)i

★ b is a real number, which means there is no imaginary part.

2a + 9 = b … (1) 6 − 3a = 0 … (2) ∴ a = 2, b = 13

Example 4

Find the complex number z such that (1 − 4i)z is a real number and z + 6 − i is a purely imaginary number.

★ Since z is complex, set unknowns on both real and imaginary parts.

Let z = a + bi.

z + 6 − i = a + bi + 6 − i = (a + 6) + (b − 1)i

Since it is a purely imaginary number, a = −6.

(1 − 4i)z = (1 − 4i)(a + bi) = a + bi − 4ai + 4b = (a + 4b) + (b − 4a)i = (−6 + 4b) + (b + 24)i

Since it is a real number, b = −24.

Example 5

(a) Simplify (i) (1 + i)² (ii) (1 − i)²

(1 + i)² = 1 + 2i + i² = 2i (1 − i)² = 1 − 2i + i² = −2i

(b) Using the results in (a), simplify √i, (1 + i)²⁰ and ((−9 − i)/(4 + 5i))²⁰

(1 + i)² = 2i

★ The large powers of a + bi in the questions are usually some neat numbers; try to split to multiples of smaller powers to convert them into a purely real/imaginary number.

(1 + i) = √(2i) √i = (1 + i)/√2 √i = (√2)/2 + (√2)/2 i (1 + i)²⁰ = [(1 + i)²]¹⁰ = (2i)¹⁰ = −1024

★ Always simplify the denominator of complex number fractions by multiplying a conjugate at the first step.

((−9 − i)/(4 + 5i))²⁰ = [((−9 − i)/(4 + 5i)) × ((4 − 5i)/(4 − 5i))]²⁰ = ((−36 + 45i − 4i − 5)/(16 + 25))²⁰ = ((−41 + 41i)/41)²⁰ = [(1 − i)²]¹⁰ = (−2i)¹⁰ = −1024

Example 6

By considering i + i² + i³ + i⁴, find the value of i + i² + i³ + i⁴ + … + i²⁰²³.

i + i² + i³ + i⁴ = i + (−1) + (−i) + 1 = 0

Usually the series involving i has a pattern for every 4 numbers.

i + i² + i³ + i⁴ + … + i²⁰²³ = 0 + 0 + … + 0 + (i − 1 − i) = −1
