Solving Quadratic Equations

Four methods, and how to pick the right one.

Four Methods Worked Examples

Four Methods to Solve a Quadratic Equation

Comparison table

Methods Best use when… Examples
1. Changing into general form and FMLA 01 Equations that can be converted to general form easily x² − 3x = −2
2. Performing factorization Both sides contain Common Factors / Identity x² − 3x = 2(x − 3)
3. Taking square roots on both sides Both sides are Perfect Squares.
Note: A² = B² → A = ±B		 (x − 3)² = 4x²
4. Using quadratic formula Cannot be factorized. Last resort. x² − 3x − 3 = 0

It is important to determine which method to use when solving a complicated equation, particularly in MC questions which always consists of extra variables.

Worked Examples

Example 1

If β is a root of the equation 3x² + 2x − 3 = 0, then 6β² + 4β − 7 =

A. 0   B. −1   C. 4   D. −4

When seeing "… is a root", immediately substitute into the equation. Rewrite the expressions into multiples of the unknowns in the equation.

Method 1 (LQ)

3β² + 2β − 3 = 0 3β² + 2β = 3 6β² + 4β = 6 ∴ 6β² + 4β − 7 = 6 − 7 = −1

Method 2 (MC)

Press FMLA 01 to get the value of β. Substitute either value into 6β² + 4β − 7 would get −1.

Example 2

If (a − 1)² − 3(a − 1) + 2 = 0 and (b − 1)² − 3(b − 1) + 2 = 0, where a < b, find the value of b − a.

A. −1   B. 0   C. 1   D. 2

Consider the expression as a quadratic equation: x² − 3x + 2 = 0, where a − 1 and b − 1 are roots of the equation.

★ Observe that the two equations given has exactly the same format of positioning of unknown.

Example 3

Solve the equation 2ax(2 − ax) + ax = 2, where a ≠ 0.

A. x = 0
B. x = 1 / (2a)
C. x = 1 / (2a) or 2 / a
D. x = 2a or a

Method 1 (LQ)

2ax(2 − ax) + ax = 2 2ax(2 − ax) − (2 − ax) = 0 (2 − ax)(2ax − 1) = 0 x = 2/a or x = 1/(2a)

Method 2 (MC)

Substitute a random number into the extra variable a, note that the number you choose needs to be unique for each of the options.

For example, when a = 2, the equation becomes 8x² − 10x + 2 = 0, solution becomes x = 1/4 or x = 1. By checking the options, option C matches the substitution.
