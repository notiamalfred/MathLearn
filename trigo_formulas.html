Maximum and Minimum values, and Trigonometric Equations.

Max & Min Values Trigonometric Equations

A) Maximum and Minimum values of Trigonometric Functions

By using the inequalities \(-1 \le \sin\theta \le 1\) and \(-1 \le \cos\theta \le 1\), we can further investigate the maximum and minimum values of sine and cosine functions in different forms.

The following assumptions are held in this chapter:

  • Unless otherwise stated, the domain of all functions in this note refer to \(0^\circ \le \theta \le 360^\circ\).
  • There is only one trigonometric function involved; in case there are more than one, convert them into the same function by using trigonometric identities.

Type 1: Linear Functions (\(y = a\sin\theta + b\) / \(y = a\cos\theta + b\))

Method: By substitution

Step 1: Let \(t = \sin\theta\) or \(t = \cos\theta\), note that \(-1 \le t \le 1\) Step 2: It is transformed to a strictly increasing/decreasing linear function \(y = at + b\). Step 3: Substitute \(t = 1\) and \(t = -1\) into the function and obtain the max/min values.

Example 1

Find the maximum/minimum value of \(y = 2\sin\theta + 3\) where \(0^\circ \le \theta \le 360^\circ\).

\[ \begin{aligned} \text{Consider the linear function } y &= 2t + 3, \\ \text{Maximum value: } y &= 2(1) + 3 = 5 \\ \text{Minimum value: } y &= 2(-1) + 3 = 1 \end{aligned} \]

Type 4: Restricted specific range

On few occasions, the question restricts the range of the trigonometric function such that it is not a must to substitute 1 and -1 all the time, particularly for CE Exam Questions.

Example 6 [Modified-2012PP-DSE-MATH-II-Q23]

Find the largest and least value of \(\frac{30}{3\sin^2\theta + 2\sin^2(90^\circ - \theta)}\) for \(135^\circ \le \theta \le 180^\circ\).

\[ \begin{aligned} \text{Note that } \frac{30}{3\sin^2\theta + 2\sin^2(90^\circ - \theta)} &= \frac{30}{3\sin^2\theta + 2\cos^2\theta} \\ &= \frac{30}{\sin^2\theta + 2} \end{aligned} \]

For \(135^\circ \le \theta \le 180^\circ\), Minimum value of \(\sin\theta = 0\) (When \(\theta = 180^\circ\))

Maximum value of \(\sin\theta = \frac{1}{\sqrt{2}}\) (When \(\theta = 135^\circ\))

\[ \text{Maximum value} = \frac{30}{0^2 + 2} = 15, \text{ minimum value} = \frac{30}{\left(\frac{1}{\sqrt{2}}\right)^2 + 2} = 12 \]

Exercises: 6. [Level 2]

Find the maximum/minimum value of these functions.

(a) \(y = 3 - 4\cos\theta\) where \(90^\circ \le \theta \le 180^\circ\) (From Exercise 1)

(b) \(y = (1 - 4\sin\theta)^2\) where \(90^\circ \le \theta \le 150^\circ\) (From Exercise 3)

(c) \(y = 2\sin^2\theta - 2\sin\theta - 4\) where \(90^\circ \le \theta \le 150^\circ\) (From Exercise 5)

(a)

For \(90^\circ \le \theta \le 180^\circ\), \(-1 \le \cos\theta \le 0\).

Maximum value \(= 3 - 4(-1) = 7\), minimum value \(= 3 - 4(0) = 3\).

(b)

For \(90^\circ \le \theta \le 150^\circ\), \(\frac{1}{2} \le \sin\theta \le 1\).

Maximum value \(= (1 - 4 \times 1)^2 = 9\), minimum value \(= \left(1 - 4 \times \frac{1}{2}\right)^2 = 1\).

(c)

\[ \begin{aligned} \text{Note that } y &= 2\left(\sin\theta - \frac{1}{2}\right)^2 - \frac{9}{2}, \quad \frac{1}{2} \le \sin\theta \le 1. \\ &\text{By substituting } \sin\theta = 1 \text{ and } \frac{1}{2}, \text{ the values are } -4, -\frac{9}{2} \text{ respectively.} \\ \text{Maximum value} &= 2\left(1 - \frac{1}{2}\right)^2 - \frac{9}{2} = -4, \text{ Minimum value} = -\frac{9}{2} \end{aligned} \]

Example 8 [Level 2]

Find the maximum/minimum value of these functions.

(a) \(y = \frac{5 - \sin\theta}{4 + \sin\theta}\) where \(0^\circ \le \theta \le 90^\circ\) (2005-CE-MATH-II-Q20)

(b) \(y = \frac{1}{(3 - 2\sin\theta)^3}\) where \(180^\circ \le \theta \le 360^\circ\)

(c) \(y = 2\tan^2\theta - 4\sqrt{3}\tan\theta + 1\) where \(180^\circ \le \theta \le 270^\circ\)

(a)

For \(0^\circ \le \theta \le 90^\circ\), \(0 \le \sin\theta \le 1\).

\[ \begin{aligned} y &= \frac{5 - \sin\theta}{4 + \sin\theta} \\ &= \frac{-(4 + \sin\theta) + 9}{4 + \sin\theta} \\ &= -1 + \frac{9}{4 + \sin\theta} \end{aligned} \]

Maximum value \(-1 + \frac{9}{4 + 0} = \frac{5}{4}\), minimum value \(-1 + \frac{9}{4 + 1} = \frac{4}{5}\).

(b)

For \(180^\circ \le \theta \le 360^\circ\), \(-1 \le \sin\theta \le 0\).

Maximum value \(= \frac{1}{[3 - 2(0)]^3} = \frac{1}{27}\), minimum value \(= \frac{1}{[3 - 2(-1)]^3} = \frac{1}{125}\).

(c)

For \(180^\circ \le \theta \le 270^\circ\), \(0 \le \tan\theta\).

\[ \begin{aligned} y &= 2\tan^2\theta - 4\sqrt{3}\tan\theta + 1 \\ &= 2(\tan^2\theta - 2\sqrt{3}\tan\theta + 3) - 6 + 1 \\ &= 2(\tan\theta - \sqrt{3})^2 - 5 \end{aligned} \]

There is no maximum value. Minimum value: \(2(0)^2 - 5 = -5\).

More Examples (f, g, h)

(f)

\[ \begin{aligned} \text{Note that } y &= \frac{2(\sin\theta - 2)^2}{\sin^2\theta - 4\sin\theta + 3} \\ &= \frac{2(\sin\theta - 2)^2}{(\sin\theta - 2)^2 - 1} \\ &= \frac{2[(\sin\theta - 2)^2 - 1] + 2}{(\sin\theta - 2)^2 - 1} \\ &= 2 + \frac{2}{(\sin\theta - 2)^2 - 1} \end{aligned} \]

Since when \(\sin\theta = 1\), \((\sin\theta - 2)^2 - 1 = 0\), there is no maximum value.

\[ \text{Minimum value} = 2 + \frac{2}{(-1 - 2)^2 - 1} = \frac{9}{4} \]

(g)

\[ \begin{aligned} \text{Note that } y &= \frac{4\sin^2\theta - 4\sin\theta - 7}{(2\sin\theta - 1)^2} \\ &= \frac{(2\sin\theta - 1)^2 - 8}{(2\sin\theta - 1)^2} \\ &= 1 - \frac{8}{(2\sin\theta - 1)^2} \end{aligned} \]

Since when \(\sin\theta = \frac{1}{2}\), \((2\sin\theta - 1)^2 = 0\), there is no minimum value.

\[ \text{Maximum value: } 1 - \frac{8}{[2(-1) - 1]^2} = \frac{1}{9}. \]

(h)

\[ \begin{aligned} \text{Note that } y &= -\tan^2\theta - 2\tan\theta \\ &= -(\tan^2\theta + 2\tan\theta + 1) + 1 \\ &= -(\tan\theta + 1)^2 + 1 \end{aligned} \]

Maximum value: \(-(0)^2 + 1 = 1\).

No minimum value.

Summarizing Exercises: 7. [Level 2]

Find the maximum/minimum value of these functions for \(0^\circ \le \theta \le 360^\circ\).

(a) \(y = 5 - 3\cos\theta\)

(b) \(y = \frac{48}{3\cos^2\theta + 4\sin^2\theta}\) (2526-WYK-S4-Final-II-Q42)

(c) \(y = \cos^2\theta - 2\cos\theta + 2\)

(d) \(y = \frac{6 + 6\sin\theta}{3 + 2\sin\theta}\)

(e) \(y = (\sin\theta + 1)^2(\sin\theta - 1)^2\)

(a)

Maximum value: \(5 - 3(-1) = 8\), Minimum value: \(5 - 3(1) = 2\)

(b)

\[ \begin{aligned} \text{Note that } y &= \frac{48}{3\cos^2\theta + 4\sin^2\theta} \\ &= \frac{48}{3\cos^2\theta + 3\sin^2\theta + \sin^2\theta} \\ &= \frac{48}{3 + \sin^2\theta} \end{aligned} \]

Maximum value: \(\frac{48}{3 + (0)} = 16\), Minimum value: \(\frac{48}{3 + (1)} = 12\)

(c)

\[ \begin{aligned} \text{Note that } y &= (\cos\theta - 1)^2 + 1, \\ \text{Maximum value: } &(-2)^2 + 1 = 5, \text{ Minimum value: } 0^2 + 1 = 1 \end{aligned} \]

(d)

\[ \begin{aligned} \text{Note that } y &= \frac{6 + 6\sin\theta}{3 + 2\sin\theta} = \frac{3(3 + 2\sin\theta) - 3}{3 + 2\sin\theta} = 3 - \frac{3}{3 + 2\sin\theta}, \\ \text{Maximum value: } &3 - \frac{3}{3 + 2(1)} = \frac{12}{5}, \text{ Minimum value: } 3 - \frac{3}{3 + 2(-1)} = 0 \end{aligned} \]

(e)

\[ \begin{aligned} \text{Note that } y &= (\sin^2\theta - 1)^2 = \cos^4\theta, \\ \text{Maximum value: } &1^4 = 1, \text{ Minimum value: } 0^4 = 0 \end{aligned} \]

C) Trigonometric Equations

This note covers some additional types of trigonometric equations that you may come across.

Type 1: Range Adjustment

This skill is applied when the unknown involves other manipulations (\(+ - \times \div\) other constants).

Example 1

Solve \(\sin 2x = \frac{1}{2}\) for \(0^\circ \le x \le 360^\circ\).

\(0 \le x \le 360^\circ \implies 0 \le 2x \le 720^\circ\)

\[ \begin{aligned} \sin 2x &= \frac{1}{2} \\ 2x &= 30^\circ \text{ or } 150^\circ \text{ or } 390^\circ \text{ or } 510^\circ \\ x &= 15^\circ \text{ or } 75^\circ \text{ or } 195^\circ \text{ or } 255^\circ \end{aligned} \]
🔑 Key: Change the range base on the size of the angle. (Rough work)
🔑 Key: Start a new cycle by adding \(360^\circ\) to the original angle, which is equivalent to adding \(180^\circ\) to the final angle.

Example 2 [2025-DSE-Math-II-Q39]

For \(90^\circ < \theta < 270^\circ\), how many roots does the equation \(\tan^3\theta = 2\tan\theta\) have?

A. 2
B. 3
C. 4
D. 5

\[ \begin{aligned} \tan^3\theta &= 2\tan\theta \\ \tan\theta(\tan^2\theta - 2) &= 0 \\ \tan\theta = 0 \text{ or } \tan\theta = \sqrt{2} \text{ or } \tan\theta &= -\sqrt{2} \end{aligned} \]

For \(90^\circ < \theta < 270^\circ\), Quadrant II is negative and Quadrant III is positive.

Therefore, there are 3 roots in total.

Type 2: Unifying same trigonometric ratio

Example 3

Solve \(3\sin^2 x - \cos x \sin x - 1 = 0\) for \(0 \le x \le 360^\circ\).

\[ \begin{aligned} 3\sin^2 x - \cos x \sin x - 1 &= 0 \\ 3\sin^2 x - \cos x \sin x - (\sin^2 x + \cos^2 x) &= 0 \\ 2\sin^2 x - \cos x \sin x - \cos^2 x &= 0 \\ 2\tan^2 x - \tan x - 1 &= 0 \\ (2\tan x + 1)(\tan x - 1) &= 0 \\ \tan x = -\frac{1}{2} \text{ or } \tan x &= 1 \\ x = 45^\circ \text{ or } 225^\circ \text{ or } 153^\circ \text{ or } 333^\circ \end{aligned} \]
🔑 Key: The constant term can be changed to multiple of \(\sin^2 x + \cos^2 x\).
🔑 Key: Divide the whole expression by \(\cos^2 x\).

Example 4

Solve \(\cos x = -\sin 40^\circ\) for \(0 \le x \le 360^\circ\).

\[ \begin{aligned} \cos x &= -\sin 40^\circ \\ \cos x &= \cos(90^\circ + 40^\circ) \text{ or } \cos x = \cos(270^\circ - 40^\circ) \\ x &= 130^\circ \text{ or } x = 230^\circ \end{aligned} \]
🔑 Key: Let \(\theta = 40^\circ\), \(\cos(90^\circ + \theta) = \cos(270^\circ - \theta) = -\sin\theta\).

Example 5

Solve \(\sin x + \sqrt{3}\cos x - 2 = 0\) for \(0 \le x \le 360^\circ\).

\[ \begin{aligned} \sin x + \sqrt{3}\cos x - 2 &= 0 \\ \sqrt{3}\cos x &= 2 - \sin x \\ 3\cos^2 x &= 4 - 4\sin x + \sin^2 x \\ 3 - 3\sin^2 x &= 4 - 4\sin x + \sin^2 x \\ 4\sin^2 x - 4\sin x + 1 &= 0 \\ (2\sin x - 1)^2 &= 0 \\ \sin x &= \frac{1}{2} \text{ (repeated)} \\ x = 30^\circ \text{ or } x &= 150^\circ \text{ (rej.)} \end{aligned} \]
🔑 Key: When the equation involves squaring both sides, you need check for the validity of the roots.

Exercises: 5. [Level 1]

Solve \(2\sin^2 x - \sin x \cos x - 5\cos^2 x = 0\) for \(0 \le x \le 360^\circ\).

(Hint: You need to use the quadratic formula first)

\[ \begin{aligned} 2\sin^2 x - \sin x \cos x - 5\cos^2 x &= 0 \\ 2\tan^2 x - \tan x - 5 &= 0 \\ \tan x &= \frac{1 \pm \sqrt{1^2 - 4(2)(-5)}}{2(2)} \\ \tan x &= \frac{1 + \sqrt{41}}{4} \text{ or } \tan x = \frac{1 - \sqrt{41}}{4} \\ x = 61.6^\circ \text{ or } 127^\circ \text{ or } 242^\circ \text{ or } 307^\circ \end{aligned} \]

Type 3: Cross-topic Applications

Example 6

\(\cos\theta\) and \(\frac{1}{\sin\theta}\) are the roots of the quadratic equation \(8x^2 + kx + 15 = 0\), where \(k\) is a constant and \(180^\circ < \theta < 270^\circ\).

(a) Find the value of \(\tan\theta\).

(b) Find the values of \(\sin\theta\) and \(\cos\theta\).

(c) Find the value of \(k\).

(a)

\[ \begin{aligned} \cos\theta \frac{1}{\sin\theta} &= \frac{15}{8} \\ \tan\theta &= \frac{8}{15} \end{aligned} \]

(b)

\[ \begin{aligned} \sin\theta &= -\frac{8}{\sqrt{8^2 + 15^2}} = -\frac{8}{17} \\ \cos\theta &= -\frac{15}{\sqrt{8^2 + 15^2}} = -\frac{15}{17} \end{aligned} \]

(c)

\[ \begin{aligned} \cos\theta + \frac{1}{\sin\theta} &= -\frac{k}{8} \\ k &= -8\left(\cos\theta + \frac{1}{\sin\theta}\right) \\ &= -8\left[-\frac{15}{17} + \left(-\frac{17}{8}\right)\right] \\ &= \frac{409}{17} \end{aligned} \]

Exercises: 13. [Level 2]

If \(\sin\theta\) and \(\cos\theta\) are the roots of the quadratic equation \(3x^2 + x - m = 0\), find the value of \(m\).

\[ \begin{aligned} \sin\theta + \cos\theta &= -\frac{1}{3} \\ \sin^2\theta + 2\sin\theta\cos\theta + \cos^2\theta &= \frac{1}{9} \\ 1 + 2\sin\theta\cos\theta &= \frac{1}{9} \\ 2\left(-\frac{m}{3}\right) &= -\frac{8}{9} \\ m &= \frac{4}{3} \end{aligned} \]
