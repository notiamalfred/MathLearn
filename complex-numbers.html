Complex Numbers

i, a + bi, conjugates, powers and series.

Basics Examples

Basics

Definition of i

Definition of i: √(−1)

i4n + r = ir for non-negative integers n and r.

Example: i2026 = i4 × 506 + 2 = i² = −1

General form a + bi

For any complex number, we consider the general form of a + bi (a and b are real numbers):

Real parta
Imaginary partb
Conjugate / another roota − bi
Reciprocal1/(a + bi) = 1/(a + bi) × (a − bi)/(a − bi)

Note: classifications of rational numbers is not applicable in numbers with non-zero imaginary part.

Examples

Example 1

(a) Express 1/(1 + 2i) in the form a + bi, where a and b are real numbers. (2 marks)

1/(1 + 2i) = 1/(1 + 2i) × (1 − 2i)/(1 − 2i) = 1/5 − (2/5)i

(b) One of the roots of the quadratic equation x² + px + q = 0 is 10/(1 + 2i).

(i) Find p and q. (3 marks)

10/(1 + 2i) = 10(1/5 − (2/5)i) = 2 − 4i Another root = 2 + 4i Sum of roots = −p/1 = (2 + 4i) + (2 − 4i) p = −4 Product of roots = q = (2 + 4i)(2 − 4i) q = 20

Alternative:

Another root = 10/(1 − 2i) = 10/(1 − 2i) × (1 + 2i)/(1 + 2i) = 2 + 4i

(ii) Find the range of values of r such that the quadratic equation x² + px + q = r has real roots. (2 marks)

Has real roots include the situation of 1 and 2 roots.

x² − 4x + 20 − r = 0 Δ = (−4)² − 4(1)(20 − r) ≥ 0 4r − 64 ≥ 0 r ≥ 16

Example 2

Let u = 7/(a + i) and v = 7/(a − i), where a is a real number. Which of the following must be true?

I. uv is a rational number.
II. The real part of u is equal to the real part of v.
III. The imaginary part of 1/u is equal to the imaginary part of 1/v.

A. I only  B. II only  C. I and III only  D. II and III only

I: uv = 49/(a² + 1), however a may not be rational.

★ Use different forms of u to evaluate quicker.

1/u = a/7 + (1/7)i, 1/v = a/7 − (1/7)i

∴ Only II is true (B).

Alternative: since a is not a constant, substitute a value into a and try by calculator.

Example 3

If (a + 3i)(2 − 3i) = b, where a and b are real numbers, find the values of a and b.

(a + 3i)(2 − 3i) = 2a + 6i − 3ai − 9i² = (2a + 9) + (6 − 3a)i

★ b is a real number, which means there is no imaginary part.

2a + 9 = b … (1) 6 − 3a = 0 … (2) ∴ a = 2, b = 13

Example 4

Find the complex number z such that (1 − 4i)z is a real number and z + 6 − i is a purely imaginary number.

★ Since z is complex, set unknowns on both real and imaginary parts.

Let z = a + bi.

z + 6 − i = a + bi + 6 − i = (a + 6) + (b − 1)i

Since it is a purely imaginary number, a = −6.

(1 − 4i)z = (1 − 4i)(a + bi) = a + bi − 4ai + 4b = (a + 4b) + (b − 4a)i = (−6 + 4b) + (b + 24)i

Since it is a real number, b = −24.

Example 5

(a) Simplify (i) (1 + i)² (ii) (1 − i)²

(1 + i)² = 1 + 2i + i² = 2i (1 − i)² = 1 − 2i + i² = −2i

(b) Using the results in (a), simplify √i, (1 + i)²⁰ and ((−9 − i)/(4 + 5i))²⁰

(1 + i)² = 2i

★ The large powers of a + bi in the questions are usually some neat numbers; try to split to multiples of smaller powers to convert them into a purely real/imaginary number.

(1 + i) = √(2i) √i = (1 + i)/√2 √i = (√2)/2 + (√2)/2 i (1 + i)²⁰ = [(1 + i)²]¹⁰ = (2i)¹⁰ = −1024

★ Always simplify the denominator of complex number fractions by multiplying a conjugate at the first step.

((−9 − i)/(4 + 5i))²⁰ = [((−9 − i)/(4 + 5i)) × ((4 − 5i)/(4 − 5i))]²⁰ = ((−36 + 45i − 4i − 5)/(16 + 25))²⁰ = ((−41 + 41i)/41)²⁰ = [(1 − i)²]¹⁰ = (−2i)¹⁰ = −1024

Example 6

By considering i + i² + i³ + i⁴, find the value of i + i² + i³ + i⁴ + … + i²⁰²³.

i + i² + i³ + i⁴ = i + (−1) + (−i) + 1 = 0

Usually the series involving i has a pattern for every 4 numbers.

i + i² + i³ + i⁴ + … + i²⁰²³ = 0 + 0 + … + 0 + (i − 1 − i) = −1
