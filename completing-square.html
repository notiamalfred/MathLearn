Completing Square

Rewrite ax² + bx + c as a(x − h)² + k.

Introduction Type 1 Type 2 Examples

Introduction

What is Completing Square?

A quadratic expression with form ax² + bx + c can be rewritten in the form of a(x − h)² + k, which we name this process as "Completing Square".

For example, x² + 4x + 5 = (x + 2)² + 1.

Type 1 — Leading Coefficient as 1

Quadratic expressions in the form x² + bx + c

  1. Divide the coefficient of x (i.e. b) by 2 to obtain the value of h in the form of (x + h)² + k.

    e.g. For x² + 4x + 5, h = 4/2 = 2, i.e. (x + 2)² + k e.g. For x² − 6x − 3, h = −6/2 = −3, i.e. (x + (−3))² + k

  2. Add the term (b/2)² (you may neglect the negative sign), and subtract back (b/2)² such that x² + bx + (b/2)² form a perfect square.

    e.g. x² + 4x + 5 = x² + 4x + (2)² − (2)² + 5 e.g. x² − 6x − 3 = x² − 6x + (3)² − (3)² − 3

  3. Simplify the residue expression (−(b/2)² + c).

    e.g. x² + 4x + 5 = (x + 2)² − 4 + 5 = (x + 2)² + 1 e.g. x² − 6x − 3 = (x − 3)² − 9 − 3 = (x − 3)² − 12

Type 2 — Leading Coefficient in Forms of Non-1

Quadratic expressions in the form ax² + bx + c

  1. Take out the factor a for the terms ax² and bx; ignore the constant term c.

    e.g. −x² + 4x + 8 = −(x² − 4x) + 8 e.g. 3x² + 6x − 1 = 3(x² + 2x) − 1

  2. Add and subtract the term (b/2)² such that x² + bx + (b/2)² inside the bracket form a perfect square.

    e.g. −x² + 4x + 8 = −(x² − 4x + (2)² − (2)²) + 8 e.g. 3x² + 6x − 1 = 3(x² + 2x + (1)² − (1)²) − 1

  3. Simplify the residue expression by −a(b/2)² + c; be careful on dealing with brackets.

    e.g. −x² + 4x + 8 = −(x² − 4x + 4) + 4 + 8 = −(x − 2)² + 12 e.g. 3x² + 6x − 1 = 3(x² + 2x + 1) − 3 − 1 = 3(x + 1)² − 4

Examples

Type 1 — Example 1

y = x² − 3x + 2 y = x² − 3x + 1.5² − 1.5² + 2 y = (x − 1.5)² − 0.25

Type 1 — Example 2

y = x² + (1/3)x + 1 y = x² + (1/3)x + (1/6)² − (1/6)² + 1 y = (x + 1/6)² + 35/36

Type 2 — Example 1

y = −2x² + 2x − 1 y = −2(x² − x) − 1 y = −2[x² − x + (1/2)² − (1/2)²] − 1 y = −2(x − 1/2)² + 1/2 − 1 y = −2(x − 1/2)² − 1/2

Type 2 — Example 2

y = (1/3)x² − x + 2 y = (1/3)(x² − 3x) + 2 y = (1/3)[x² − 3x + (3/2)² − (3/2)²] + 2 y = (1/3)(x − 3/2)² − 3/4 + 2 y = (1/3)(x − 3/2)² + 5/4

Type 2 — Example 3

y = 2x² + 4kx + 3k² − 1 y = 2(x² + 2kx) + 3k² − 1 y = 2[x² + 2kx + k² − k²] + 3k² − 1 y = 2(x + k)² − 2k² + 3k² − 1 y = 2(x + k)² + k² − 1
